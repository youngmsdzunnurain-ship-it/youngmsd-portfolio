# Young MSD — Developer Portfolio

A responsive personal portfolio for **Mas’ud Adebiyi (Young MSD)**, a frontend and React Native developer based in Abuja, Nigeria.

The site presents an introduction, services, selected projects, technical skills, development journey, and contact options.

## Built with

- HTML5
- CSS3 (custom responsive styling, animations, and light/dark theme)
- Vanilla JavaScript
- Google Fonts (Bricolage Grotesque and Figtree)

The portfolio itself is a static website. React and React Native are part of the developer's showcased skills; they are not required to run this page.

## Run locally

No package installation or build step is required.

From the project root, run:

```bash
php -S 127.0.0.1:8085
```

Then open:

```text
http://127.0.0.1:8085
```

Stop the server with `Ctrl + C`.

You can also open `index.html` directly in a browser, although using the local server is recommended for testing.

## Project structure

```text
youngmsd-portfolio/
├── index.html
└── README.md
```

The current page keeps its CSS and JavaScript in `index.html`, and the project preview images are embedded in that file.
