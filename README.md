# Young MSD — Developer Portfolio

A responsive personal portfolio for **Mas’ud Adebiyi (Young MSD)**, a frontend and React Native developer based in Abuja, Nigeria.

The site presents an introduction, services, selected projects, technical skills, development journey, and contact options.

## Built with

- HTML5
- CSS3 — responsive layout, animations, and light/dark theme
- Vanilla JavaScript
- Google Fonts — Bricolage Grotesque and Figtree

This is a static website. No framework installation or build step is required.

## Project structure

```text
youngmsd-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

- `index.html` contains the page structure and content.
- `css/style.css` contains the original page styles.
- `js/script.js` contains the original interactions and behavior.
- The portfolio's embedded image data is retained as-is to preserve the existing visuals.

## Run locally

From the project root, start PHP's built-in development server:

```bash
php -S 127.0.0.1:8085
```

Open:

```text
http://127.0.0.1:8085
```

Stop the server with `Ctrl + C`.

No dependencies need to be installed.

## Before publishing
